IKEA drawing ↔ 3D model

The drawing's numbers on the 3D model

Each published dimension is drawn here at the place it measures on IKEA's own web 3D model (GLB), with the length measured from the model's geometry next to it. Drag to orbit, scroll to zoom, hover a label or a row to isolate it.

Drawing vs. model

Drawing = IKEA's published dimension. Model = the same length measured on the GLB's vertices.

DimensionDrawingModelΔ

The model is a lightweight web asset, so small differences are expected. How each length is measured is set in the spec JSON used by fit_dimensions.py.
